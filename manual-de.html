📘 Gebrauchsanleitung für flashterm

Terminologie- und Wissensmanagement leicht gemacht

Einführung

flashterm richtet sich an alle Mitarbeitenden, die beim Erstellen oder Prüfen von Texten definierte Begriffe verwenden möchten, eine Vokabelliste zur Übersetzung bereitstellen wollen oder einfach einen Begriff besser verstehen möchten – unabhängig von Rolle, Fachbereich oder Sprachniveau.

Funktionsübersicht

  • Suchfeld: Eingabe eines Begriffs mit sofortiger Vorschlagsliste
  • Tastatursteuerung: Navigation durch Vorschläge per Pfeiltasten und Auswahl per Enter
  • Modusauswahl: Drei Modi: Wiki, Inspector, Translator
  • Sprachumschaltung: Zielsprachen dynamisch auswählbar
  • Term-Mining: Analyse von Texten zur Begriffsidentifikation
  • Export: Gefundene Begriffe als Excel oder JSON exportieren
  • Zwischenablage: Texte aus der Zwischenablage einfügen und automatisch prüfen oder übersetzen lassen
  • URL-Parameter: Sprachkombination direkt über die URL anwählbar

Bedienung Schritt für Schritt

1. Start und Suche

Öffnen Sie die Anwendung im Browser und geben Sie im Suchfeld einen Begriff ein. Die Vorschlagsliste öffnet sich automatisch.

2. Vorschläge nutzen

– Navigieren Sie mit ↓ / ↑ durch die Vorschläge.
– Drücken Sie Enter, um den markierten Vorschlag auszuwählen.
– Alternativ: Klicken Sie mit der Maus auf einen Vorschlag.
Tipp: Wenn Sie die Vorschlagsliste mit der Maus verschieben (z. B. zur Seite), bleibt sie dauerhaft geöffnet. Das erleichtert das systematische Abarbeiten mehrerer Begriffe, ohne die Liste bei jedem neuen Suchwort erneut öffnen zu müssen.

3. Wissensanzeige (Wiki)

Sie sehen: Vorzugsbenennungen, Definitionen, Kontexte, Synonyme, Infobox. Schalten Sie die Sprache um: Klick auf [de] / [en] usw.

4. Modus wechseln

  • Wiki: Begriffseinzelanzeige
  • Inspector: Textanalyse (mit Begriffserkennung)
  • Translator: Begriffe mit Zielsprachübersetzung

5. Textanalyse (Term-Mining)

– Kopieren Sie einen Text (Strg+C) und fügen Sie ihn in das Suchfeld ein (Strg+V).
– Analyse in der Ausgangssprache startet automatisch
– Gefundene Begriffe werden markiert: Haken im Kreis = bevorzugt, leerer Kreis = alternativ, durchgestrichener Kreis = nicht verwenden.
– Wechseln Sie in den Modus Translator.
– Gefundene Begriffe werden mit der Vorzugsbenennung der Zielsprache übersetzt.

6. Sprachkombination per URL steuern

Rufen Sie die Seite beispielsweise so auf:
https://ihre-domain.de/index.html?source=de-DE&target=en-US

Die gültigen Sprachcodes finden Sie in der Sprachauswahl von flashterm. Tipp: Nach dem Wechseln einer Zielsprache sehen Sie die für Ihre Domain gültige URL.

Ungültige Sprachcodes werden ignoriert – in diesem Fall verwendet das System die Voreinstellung.

7. Exportieren

Klicken Sie auf das Export-Icon 📤 unter der Tabelle, um die Daten zu speichern.

Tastenkombinationen

  • ↓ = nächsten Vorschlag markieren
  • ↑ = vorherigen Vorschlag markieren
  • Enter = Auswahl öffnen

Tipps & Hinweise

  • Der Dunkelmodus wird automatisch erkannt
  • Suchfeld-Reset per Klick auf das „x“-Icon
  • Profil-Icon öffnet Spracheinstellungen
  • Markdown erlaubt Formatierungen in der Infobox

Technik

  • Empfohlene Browser: Chrome, Firefox, Safari, Edge
  • JavaScript muss aktiviert sein
  • Internetverbindung erforderlich für Datenabruf
